### 目前折腾出的一些项目

- 📖 [**Resonance Vault (共鸣典藏馆)**](https://github.com/eryuemu/resonance-vault)  
  面向珍藏数字音乐的 3D 离线物理画册归档程序。尝试将音乐物化为精装实体书，还原双联开卷、中缝装订阴影与黑胶滑出动效。

- 🐋 [**world.execute(me); Cyber Whale Player**](https://github.com/eryuemu/ai-passport-world-execute-me)  
  FoloToy AI Passport (ESP32-C3 随身透明工牌) 专属离线播放器固件。纯 C 硬件直驱、差分解码与音画同步。

- ⌨️ [**Colorful Keyboard LED Color Setting**](https://github.com/eryuemu/Colorful-Keyborad-Led-Color-Setting)  
  专为七彩虹隐星系列笔记本打造的纯净绿色键盘灯光调节工具。基于底层 `InsydeDCHU.dll` 驱动开发与 x64 编译，解决闪退并重构现代深色能量条 UI。

- 🌸 [**Bad Apple!! 汉字点阵流变**](https://github.com/eryuemu/bad-apple-easter-egg)  
  轻量零依赖的网页端彩蛋库，实现 60 FPS 汉字点阵活体流变与全息透明剪影双模态。

- 🏛️ [**HBU-Wiki**](https://github.com/eryuemu/HBU-Wiki)  
  校友共建的河北大学维基百科，整理真实的校园生活与学业经验，打破信息孤岛。
